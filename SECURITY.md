# Security policy

Report suspected SFC vulnerabilities through the
[private GitHub report form](https://github.com/fhajjej-ship-it/sfc-codex/security/advisories/new).
GitHub shares the report privately with the repository maintainers.

Include the SFC version, the affected component or workflow, and the impact
you observed. Use test data and remove live credentials, private repository
content, and personal information from any examples or logs.

We use the private report to coordinate investigation, a fix, and disclosure.
For setup help, feature ideas, and ordinary bugs, use
[public GitHub Issues](https://github.com/fhajjej-ship-it/sfc-codex/issues/new/choose).
