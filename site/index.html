Simulated GitHub Project

    Install in Codex

    Use macOS or Linux with Python 3.10+, Git, and authenticated Codex and GitHub CLIs. Stop an active SFC watcher before upgrading.

    Terminal 
    curl -fsSLo sfc-install.py https://raw.githubusercontent.com/fhajjej-ship-it/sfc-codex/@TAG@/scripts/install_release.py && python3 sfc-install.py --version @VERSION@

    Reopen Codex, review the SFC hooks, then onboard the GitHub Project you want to use.
